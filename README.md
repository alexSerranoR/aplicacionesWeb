# Centro de formación

Aplicación web para gestionar un centro de formación: cursos, docentes, aulas, alumnos y matrículas.
Práctica obligatoria de Aplicaciones Web (Grado en Ingeniería del Software).

**Autores:** Nico y Alex

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid y media queries)
- JavaScript

## Cómo ejecutarla

Abrir `index.html` en el navegador, o usar la extensión Live Server de Visual Studio Code.

## Estructura del proyecto

```
index.html     Página de inicio
css/           Hoja de estilos común (styles.css)
js/            JavaScript común (main.js)
img/           Logo, favicon e imágenes de cursos y docentes
paginas/       Resto de pantallas
               - Públicas: login, registro
               - Alumno: cursos, detalle-curso, docentes, aulas,
                 mis-matriculas, perfil, accesibilidad, cerrar-sesion
               - Administrador: administracion y admin-*.html
```
